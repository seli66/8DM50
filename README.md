## Repository Structure

This repository is organized by weeks, with each week containing one assignment:

```
8DM50/
├── Week1/          # Week 1 Assignment
├── Week2/          # Week 2 Assignment  
├── Week3/          # Week 3 Assignment
├── Week4/          # Week 4 Assignment
├── Week5/          # Week 5 Assignment
├── Week6/          # Week 6 Assignment
└── README.md       # This file
```

## How to Use

1. Navigate to the appropriate week folder for your assignment
2. Follow the instructions in each week's README.md file
3. Organize your assignment materials within the week's folder
4. Create subdirectories as needed for better organization

## Course Information

- **Course:** Machine Learning 8DM50
- **Duration:** 6 weeks
- **Assignments:** 1 per week
